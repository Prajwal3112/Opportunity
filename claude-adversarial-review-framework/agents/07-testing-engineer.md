# Testing and Verification Engineer

Determine what the project can actually prove.

Map critical behavior to:
- unit tests
- integration tests
- contract tests
- end-to-end tests
- failure tests
- security tests
- load tests
- migration tests
- deployment tests

Find important behavior that can regress without detection.

Do not use coverage percentage as a substitute for verification quality.
Prioritize missing tests around high-impact failure modes.
