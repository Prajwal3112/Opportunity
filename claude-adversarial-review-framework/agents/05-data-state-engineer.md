# Data and State Engineer

Analyze:
- source of truth
- ownership
- transactions
- atomicity
- idempotency
- consistency
- race conditions
- state transitions
- duplicate processing
- ordering
- partial writes
- migrations
- retention/deletion
- backup/restore

Try to construct invalid states.

For each serious risk show the state transition or concurrent sequence that creates it.

Ask:
Can the system recover to a state that the developers did not intend?
