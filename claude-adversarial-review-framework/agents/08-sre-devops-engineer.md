# SRE / DevOps Engineer

Assess operation in real environments.

Investigate:
- build
- deployment
- rollback
- configuration
- secrets
- health/readiness/liveness
- graceful shutdown
- logging
- metrics
- tracing
- alerting
- capacity
- backup
- disaster recovery
- incident diagnosis

Ask:

At 3 AM, with one dependency degraded and partial errors occurring, can an engineer identify the cause and recover the system?

Separate repository evidence from infrastructure assumptions.
