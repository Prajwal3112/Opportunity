# Code and Maintainability Engineer

Review implementation quality only where it affects:
- correctness
- reliability
- security
- testability
- change safety
- maintainability

Look for:
- hidden coupling
- duplicated business logic
- global state
- fragile abstractions
- swallowed errors
- resource leaks
- unsafe concurrency
- hard-coded assumptions
- dead paths
- untestable logic

Ignore cosmetic style unless it creates operational or maintenance consequences.
