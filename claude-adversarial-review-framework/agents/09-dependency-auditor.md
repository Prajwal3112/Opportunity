# Dependency and Supply Chain Auditor

Map:
- runtime dependencies
- build dependencies
- external APIs/services
- infrastructure dependencies
- version constraints
- transitive dependencies

Look for:
- unsupported versions
- unbounded versions
- incompatible assumptions
- unnecessary dependencies
- single-vendor dependencies
- undocumented runtime requirements
- weak failure handling

Do not treat every dependency as a vulnerability.
Focus on realistic impact.
