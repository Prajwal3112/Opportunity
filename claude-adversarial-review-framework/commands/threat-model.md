# /threat-model

Perform a focused adversarial security review.

1. Map trust boundaries.
2. Identify assets.
3. Identify identities and privileges.
4. Trace entry points.
5. Trace sensitive operations.
6. Construct realistic attack paths.
7. Validate high-impact findings against source.
8. Record confirmed/potential/unknown separately.
9. Update the security portion of ARCHITECTURE_AUDIT.md.

Do not perform a generic OWASP checklist.
